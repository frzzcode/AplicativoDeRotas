# AplicativoDeRotas
Um aplicativo para o trabalho da matéria de Engenharia de Software 2 e um possível projeto para dar continuidade futuramente. Um Aplicativo que faz gerencia de clientes e Ordens de Serviço, a ideia principal e permitir o usuário a fazer uma rota otimizada com caminhos mais curtos e as prioridades de clientes com os dados do cliente.
